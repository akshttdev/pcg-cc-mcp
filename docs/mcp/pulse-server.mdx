# PulseMCP Reference

PulseMCP provides real-time content monitoring and analysis through 6 MCP tools. The Pulse Engine collects content from configured sources (news, articles, social media) and surfaces relevant items to agents and users.

**Binary**: `mcp_pulse_server`
**Transport**: stdio

## Tools

### `search_pulse_content`

Search collected content by keyword or source.

<ParamField query="project_id" type="string" required>
UUID of the project.
</ParamField>

<ParamField query="keyword" type="string">
Search keyword to match against titles and summaries.
</ParamField>

<ParamField query="source_id" type="string">
Filter by specific content source.
</ParamField>

<ParamField query="limit" type="integer" default="20">
Maximum results to return.
</ParamField>

### `get_latest_pulse_content`

Get the most recently collected content items.

<ParamField query="project_id" type="string" required>
UUID of the project.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Maximum items to return.
</ParamField>

### `trigger_pulse_collection`

Manually trigger content collection from a specific source.

<ParamField body="project_id" type="string" required>
UUID of the project.
</ParamField>

<ParamField body="source_id" type="string" required>
UUID of the source to collect from.
</ParamField>

### `get_pulse_status`

Get the current status of the Pulse Engine for a project, including active sources and collection health.

<ParamField query="project_id" type="string" required>
UUID of the project.
</ParamField>

### `create_task_from_pulse`

Convert a content item into a task for follow-up action.

<ParamField body="project_id" type="string" required>
UUID of the project.
</ParamField>

<ParamField body="content_item_id" type="string" required>
UUID of the Pulse content item.
</ParamField>

<ParamField body="title" type="string" required>
Title for the new task.
</ParamField>

<ParamField body="description" type="string">
Task description. If omitted, the content item's summary is used.
</ParamField>

### `list_pulse_alerts`

Get recent alerts generated by content analysis.

<ParamField query="project_id" type="string" required>
UUID of the project.
</ParamField>

<ParamField query="limit" type="integer" default="10">
Maximum alerts to return.
</ParamField>

Alerts are generated when content matching configured criteria is detected — for example, competitor announcements, security advisories, or trending topics relevant to the project.
