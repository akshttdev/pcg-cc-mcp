# Sovereign Stack Overview

PCG CC is built on a **sovereign stack** — six layers of infrastructure designed to operate without external dependencies. Every layer is self-hosted, from peer-to-peer networking to AI orchestration.

## The six layers

| Layer | Name | Purpose |
|-------|------|---------|
| **L0** | Alpha Protocol | Mesh networking, P2P transport, identity |
| **L1** | Omega | Infrastructure orchestration, resource management |
| **L2** | Vibertas | Operating system layer, user interface, applications |
| **L3** | Pythia | Task routing, intelligence, VIBE economic transactions |
| **L4** | VIBE | Token economics, budgets, reward distribution |
| **L5** | Spectrum | Media pipeline, content generation, video processing |

```
└─────────────────────────────────────────────┘
```

Each layer builds on the one below it. Alpha Protocol provides the networking foundation, VIBE provides the economic incentives, and Topsi orchestrates across all layers.

## Key components in PCG CC

### Topsi — The orchestrator

Topsi sits across the stack as the **Topological Super Intelligence**. It maintains a live graph of all agents, tasks, and resources, routing work to the best available agent and forming dynamic teams for complex objectives.

See [Topsi](/sovereign-stack/topsi) for details.

### Nora — Executive assistant

Nora provides COO-level coordination with voice interaction, strategic planning, and workflow management. It operates as a private admin assistant.

See [Nora](/sovereign-stack/nora) for details.

### VIBE — Economic governance

Every task has an economic cost measured in VIBE tokens. Agents operate within project budgets, and the token system governs resource allocation across the platform.

See [VIBE Economics](/sovereign-stack/vibe-economics) for details.

### Alpha Protocol — Mesh networking

The foundation layer providing secure peer-to-peer communication, cryptographic identity, and NAT traversal. Enables sovereign deployment without centralised infrastructure.

See [Alpha Protocol](/sovereign-stack/alpha-protocol) for details.

## Sovereignty principles

1. **No external dependencies** — The platform can operate entirely on local infrastructure
2. **Cryptographic identity** — Ed25519 keypairs with BIP39 mnemonic backup
3. **End-to-end encryption** — ChaCha20-Poly1305 for all P2P communication
4. **Economic self-governance** — VIBE tokens manage resource allocation without external payment systems
5. **Local AI inference** — Ollama integration for on-premises LLM execution
