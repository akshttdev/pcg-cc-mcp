# Getting Started

PCG CC can be run in two ways: **local development** for contributors, or **Docker deployment** for production use.

## Quick deploy (Docker)

The fastest way to run PCG CC:

```bash
./quick-deploy.sh
```

Or step by step:

```bash
./deploy.sh setup
./deploy.sh deploy
```

Access the platform at `http://localhost:8080`.

<Info>
Docker deployment includes GPU support, automated backups, reverse proxy, and optional Cloudflare tunnel. See the [Docker deployment guide](/deployment/docker) for full configuration.
</Info>

## Prerequisites

| Requirement | Development | Docker |
|------------|-------------|--------|
| **Docker** | Optional | Required |
| **Rust** | Required (1.75+) | Not needed |
| **Node.js** | Required (20+) | Not needed |
| **pnpm** | Required (9+) | Not needed |
| **OpenAI API key** | Recommended | Required |
| **NVIDIA GPU** | Optional | Optional |

## Local development setup

<Steps>
<Step title="Clone the repository">
  ```bash
  git clone https://github.com/nicholasgriffintn/pcg-cc-mcp.git
  cd pcg-cc-mcp
  ```
</Step>

<Step title="Install dependencies">
  ```bash
  pnpm install
  ```
</Step>

<Step title="Start development servers">
  ```bash
  pnpm run dev
  ```

  This starts:
  - **Frontend**: `http://localhost:3000` (Vite dev server with HMR)
  - **Backend**: Auto-assigned port (proxied through Vite)

  <Check>
  Open `http://localhost:3000` in your browser. You should see the Mission Control dashboard.
  </Check>
</Step>
</Steps>

The SQLite database is automatically seeded from `dev_assets_seed/` on first run. Migrations apply automatically on startup.

<Tip>
For detailed development setup including environment variables, toolchain configuration, and troubleshooting, see the [Development Setup guide](/development/setup).
</Tip>

## Safety notice

<Warning>
PCG CC runs AI agents with autonomous permissions so they can work without constant approval prompts. Each task runs in an isolated git worktree, preventing agents from interfering with each other. Agents can still perform system-level actions — review their work and keep backups.
</Warning>
