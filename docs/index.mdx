# PCG Command Centre

PCG CC is a **sovereign AI orchestration platform** that coordinates multiple AI agents across complex software projects. Built on Rust/Axum with a React frontend, it provides task management, agent topology, knowledge tracking, and economic governance through the VIBE token system.

## What makes PCG CC different

<CardGroup cols={2}>
  <Card title="Topology Intelligence" icon="diagram-project">
    Topsi manages a live graph of agents, tasks, and resources — routing work to the best available agent and forming dynamic teams for complex objectives.
  </Card>
  <Card title="Orchestration Context" icon="chalkboard">
    A shared blackboard system where agents share findings, decisions, blockers, and intermediate results across parallel task trees.
  </Card>
  <Card title="VIBE Economics" icon="coins">
    Every task has an economic cost. Agents operate within project budgets, and the token system governs resource allocation across the platform.
  </Card>
  <Card title="Sovereign Stack" icon="shield-halved">
    Six layers from Alpha Protocol (mesh networking) to Spectrum (media pipeline), all self-hosted with no external dependencies.
  </Card>
</CardGroup>

## Platform at a glance

| Component | Technology | Scale |
|-----------|-----------|-------|
| Backend | Rust, Axum, SQLite, Tokio | 17 crates, 103 route files |
| Frontend | React 18, TypeScript, Vite, Tailwind | 36 pages, 51 component dirs, 55 hooks |
| Database | SQLite with SQLx | 111 models, 136 migrations |
| MCP Servers | rmcp (Rust MCP) | 4 servers, 24+ tools, 7 resources |
| Agents | Topsi, Nora, configurable | Multi-provider (Claude, Gemini, etc.) |
| Deployment | Docker, systemd, Tauri desktop | GPU support, mesh networking |
