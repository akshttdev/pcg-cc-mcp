# Frontend Architecture

The frontend is a React 18 + TypeScript application built with Vite, styled with Tailwind CSS and shadcn/ui components.

## Stack

| Layer | Technology |
|-------|-----------|
| Framework | React 18.x with TypeScript |
| Build | Vite |
| Styling | Tailwind CSS + shadcn/ui |
| State | React Query (TanStack Query) for server state |
| Routing | React Router |
| Real-time | Server-Sent Events (SSE) + WebSocket |

## Design system

The design system uses a surface elevation model with glass morphism effects:

### Colour tokens
```css
--brand: 217 91% 60%;           /* Electric blue */
--surface-0: base background
--surface-1: cards, panels
--surface-2: raised elements
--surface-3: highest elevation
```

### Component patterns

- **Cards**: `rounded-xl`, `shadow-elevation-1`, hover glow effects
- **Glass morphism**: `backdrop-blur-xl` with opacity layers for navbar and headers
- **Tabs**: Underline style with `border-b-2` active indicator
- **Buttons**: Compact (`h-9`), `active:scale-[0.98]` feedback
- **Status dots**: Colour-coded with glow shadows (online, offline, warning, error)

### Utility classes

The design system provides 50+ reusable utility classes in `styles/index.css`:

```css
.page-container    /* Responsive container with max-w-[1600px] */
.page-header       /* Flex header with responsive layout */
.card-elevated     /* Card with shadow and hover effect */
.card-interactive  /* Card with lift-on-hover animation */
.glass-strong      /* Strong glass morphism background */
.stat-grid         /* 2/4-column responsive stat grid */
.empty-state       /* Centred empty state layout */
.status-dot-online /* Green dot with glow shadow */
```

## Data flow

### Server state

All server data flows through React Query. API calls go to the Axum backend which proxies through Vite in development:

```
Component → useQuery/useMutation → fetch('/api/...') → Axum → SQLite
```

### Real-time updates

Task execution logs and diffs stream via SSE:

```
Axum SSE endpoint → EventSource → useEventSourceManager hook → Component
```

### Type safety

TypeScript types are auto-generated from Rust structs via `ts-rs`. The `shared/types.ts` file is the single source of truth:

```bash
npm run generate-types    # Regenerate after Rust type changes
npm run generate-types:check  # Verify types match
```

<Warning>
Never manually edit `shared/types.ts`. It is generated by `crates/server/src/bin/generate_types.rs` and will be overwritten.
</Warning>

## Mobile support

The frontend is mobile-responsive with a drawer sidebar pattern:

- **Mobile** (`< lg`): Sidebar slides in from left, auto-closes on navigation
- **Desktop** (`>= lg`): Sidebar is static, always visible
- The navbar includes a hamburger toggle for mobile sidebar control
